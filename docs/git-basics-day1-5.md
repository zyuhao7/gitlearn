## 一张图理解三层

```text
工作区 -> 暂存区 -> 本地仓库
```

- 工作区：你正在编辑的文件。
- 暂存区：准备进入下一次提交的改动。
- 本地仓库：已经提交保存的历史。

中间那层是新手最容易漏掉的一步，也是最值得记住的设计。它让你能挑着提交：改了三处只想提交其中一处，把要提交的那部分 `git add` 进去就行，其余留在工作区继续改。

## 两个容易混的地方

- 改文件和保存版本是两件事。`git add` 只是“准备提交”，`git commit` 之后才真正进入历史。
- 每次提交保存的是当时的完整快照，不是“跟上一版的差异”。回看历史时看到的是那一刻整个项目的状态。

## 学完这 5 天

- 知道 Git 解决什么问题
- 能初始化仓库并完成第一次提交
- 能看懂 `git status` 各种提示的含义
- 能用 `git log --oneline` 回看历史
